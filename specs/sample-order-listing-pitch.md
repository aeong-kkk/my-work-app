# 개발샘플현황표 자동화 — 1분 발표 원고

안녕하세요. 오늘 소개할 건 "개발샘플현황표 자동화" 프로그램입니다.

**[무엇을]**
저희는 샘플을 발주할 때마다, 발주에 쓰는 엑셀 파일 안에서 모델명, 수량, 날짜 같은 정보를 사람이 직접 보고 표로 옮겨 적고 있어요. 이 프로그램은 그 작업을 대신 해서, 발주 내역을 자동으로 정리된 리스트로 만들어줍니다.

**[왜]**
발주는 할 때마다 반복되는 일이고, 매번 파일을 열어서 필요한 정보를 하나하나 찾아 옮겨야 해서 손이 많이 가고 번거로워요. 특히 수량이 여러 건으로 나뉘면 더 헷갈리고요. 정해진 양식에서 정해진 정보만 뽑아 정리하는 단순 반복 작업이라, 자동화하기 딱 좋은 일이라고 생각했습니다.

**[어떻게]**
방법은 간단합니다. 발주할 때 쓰는 엑셀 파일을 화면에 끌어다 놓기만 하면 돼요. 그러면 프로그램이 파일 안에서 모델명, 수량, 요청일 같은 필요한 정보를 자동으로 찾아 읽습니다. 그다음 발주일과 요청일 사이 기간, 즉 리드타임을 자동으로 계산하고요. 빠진 정보가 있거나 이미 넣었던 내용이면 알아서 표시하거나 걸러줍니다. 마지막으로 이 모든 내용을 엑셀 리스트 하나에 차곡차곡 쌓아서 저장해줍니다.

감사합니다.
