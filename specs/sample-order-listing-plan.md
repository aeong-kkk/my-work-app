# 샘플발주 내역 리스트화 — 기획서

## 목표
발주할 때마다 첨부 엑셀(Info 시트)을 앱에 드래그 앤 드롭하면, 발주일·요청일·모델명·내부명·수량·층구성을 자동으로 뽑아 리드타임(일수)까지 계산한 정리된 리스트를 만들어준다.

## 입력
- 앱 화면에 드래그 앤 드롭으로 넣는 첨부 엑셀 파일 (시트: Info 1개뿐 — 예전엔 Packing 시트가 따로 있었지만 지금은 Info 시트 안 "Shipping Information" 구역으로 통합됨)
- 한 번에 여러 파일을 동시에 넣을 수 있음 — 파일마다 아래 처리를 각각 적용
- 발주일은 파일 안(Info 시트 G1)에 직접 기입되어 있음

## 단계
1. 앱 화면에 드래그 앤 드롭된 엑셀 파일들을 입력받기 (여러 개 가능)
2. 파일을 하나씩 순서대로 처리
3. 파일에 "Info" 시트가 있는지 확인
4. 시트가 없거나 구조가 예상과 다르면 에러로 알리고 해당 파일은 건너뛰기 (다음 파일 계속 처리)
5. "Info" 시트 열기
6. G1 셀 값 읽기 → 발주일
7. F5 셀 값 읽기 → 모델명 (Customer Model Name)
8. F6 셀 값 읽기 → 내부명 (Internal Model Name)
9. G18 셀 값 읽기 → Total-T (板厚)
10. G19 셀 값 읽기 → 층구성
11. "Shipping Information" 구역(I열, 3행부터)에 값이 입력된 행을 전부 확인 — 값이 하나도 없으면 에러
12. 확인된 행 개수만큼, 각 행의 I열 값 읽기 → 수량
13. 확인된 행 개수만큼, 각 행의 M열 값 읽기 → 요청일
14. 행 개수만큼 발주 건 생성 (발주일/모델명/내부명/Total-T/층구성은 공통 적용)
15. 요청일에 연도 보정
16. 행이 여러 개면서 요청일이 서로 다르면, 가장 늦은 요청일인 행은 구분을 "분할입고"로 덮어씀 (원래 신규발주/재발주였어도 적용). 행이 1개거나 요청일이 전부 같으면 적용 안 함
17. 수량 값에서 숫자만 분리
18. 발주일·요청일로 리드타임(일수) 계산 = 요청일 - 발주일
19. 값 앞뒤 공백·줄바꿈 제거
20. 기존 리스트에 모델명·발주일·수량이 모두 같은 행이 이미 있는지 확인
21. 이미 있으면 중복으로 보고 이 건은 리스트에 추가하지 않음
22. 필수 항목(발주일/요청일/모델명/내부명/Total-T/수량/층구성) 비어있는지 확인
23. 비어있으면 "누락" 플래그 추가
24. 정리된 값들을 한 행으로 묶기
25. 새로 추가할 발주 건의 행을 모아 표로 합치기
26. 표를 발주일 기준 날짜순으로 정렬
27. 정렬된 표를 기존 리스트 파일(엑셀)에 누적 저장

## 출력
- **형식**: 엑셀(xlsx) 표. 실행할 때마다 새 파일을 만들지 않고, 기존 리스트 파일 맨 아래에 새 발주 건 행을 누적(추가)
- **정렬**: 발주일 기준 날짜순
- **컬럼**: 발주일 / 구분(신규발주·재발주·분할입고) / 요청일 / 모델명 / 내부명 / Total-T / 수량 / 층구성 / 리드타임(일수) / 비고
  - 구분 — 신규발주/재발주가 기본값이며, 한 파일 안에 요청일이 서로 다른 행이 여러 개 있으면 그중 가장 늦은 요청일인 행만 "분할입고"로 덮어씀
  - 비고 — 처리 단계(22~23번)에서 나온 "누락" 플래그를 표시. 문제 없으면 빈 칸
- **한 발주 건이 여러 행이 되는 경우**: "Shipping Information" 구역에 행이 여러 개면 발주일·모델명·내부명·Total-T·층구성은 동일하게 반복되고, 수량·요청일·리드타임·비고만 행마다 달라짐

### 예시 (참고 파일 `New-2.xlsx` 기준)

발주일은 파일 안 Info 시트 G1 값(2026-07-23)을 그대로 사용합니다. "Shipping Information" 구역에 두 행(수량 500·90)이 있고 둘 다 요청일(2026-08-01)이 채워져 있어 누락 없이 리드타임이 정상 계산됩니다.

| 발주일 | 요청일 | 모델명 | 내부명 | Total-T | 수량 | 층구성 | 리드타임(일수) | 비고 |
|---|---|---|---|---|---|---|---|---|
| 2026-07-23 | 2026-08-01 | A | ABC | 0.512T | 500 | 10L/FVSS3 | 9 | |
| 2026-07-23 | 2026-08-01 | A | ABC | 0.512T | 90 | 10L/FVSS3 | 9 | |

## 제약
- 첨부파일에 "Info" 시트가 없거나 셀 구조(G1/F3/F5/F6/G18/G19, Shipping Information I·M열)가 예상과 다르면: 에러로 알리고 해당 파일만 건너뜀. 나머지 파일은 계속 처리
- 같은 발주 건(모델명·발주일·수량이 모두 동일)을 다시 넣으면: 중복으로 감지해 리스트에 추가하지 않음
- 수량·리드타임에 대한 "이상치" 자동 판정은 하지 않음 — 값이 비어있는지("누락")만 확인
- 한 번에 여러 파일을 동시에 드래그 앤 드롭 가능하며, 파일마다 성공/건너뜀(구조 오류)/중복 여부가 각각 따로 적용됨
