# 개발단계·승인원 일정 관리 — 명세

> `streamlit_app.py`에 새 탭으로 추가하는 화면 기능. 기능 1(발주 리스트)처럼 화면 전용이며,
> `featureN_*.py` 스크립트나 `.claude/skills/` 스킬로는 등록하지 않는다 (streamlit_app.py 자체가
> 그런 것처럼). 발주 1건(모델명 기준)마다 지금 어느 개발단계에 있는지, 승인원 일정이 언제인지를
> 사람이 직접 입력해서 보드(칸반)·캘린더 형태로 확인한다.

## 목적
발주 리스트(기능 1)만으로는 알 수 없는 "지금 이 모델이 개발 어느 단계인지, 승인원은 언제
받기로 했는지"를 별도로 기록하고 한눈에 보이게 한다.

## 데이터 모델
발주 1건(모델명)당 아래 항목을 갖는 레코드 1개:

| 필드 | 설명 |
|---|---|
| 모델명 | 발주 리스트에 이미 있는 모델명 중 선택, 또는 새로 직접 입력 |
| 개발단계 | DV / DVR / PV / PVR 중 선택. DV·PV를 고르면 "차수"(1차, 2차, …) 추가 입력 → 최종 값은 "DV1차", "PV2차", "DVR", "PVR" 같은 문자열 |
| 승인원 일정 | 날짜 1개 (승인원 제출/승인 예정일) |
| 비고 | 자유 텍스트 (선택 입력) |

- 개발단계 순서(진행 순서 기준): DV1차 → DV2차 → … → DVR → PV1차 → PV2차 → … → PVR
- 한 모델에 대해 여러 레코드가 쌓일 수 있음 (단계가 바뀔 때마다 새로 추가 — 기존 값을 덮어쓰지 않고
  이력처럼 쌓는다. 보드에는 모델별 "가장 최근 단계"만 대표로 보여줌)

## 입력 방식
- 화면(Streamlit) 폼으로 사람이 직접 입력 — 엑셀이나 다른 파일에서 자동으로 가져오지 않음
- 입력 항목: 모델명(텍스트/선택), 개발단계(선택 + 차수), 승인원 일정(날짜 선택), 비고(텍스트)
- "추가" 버튼으로 레코드 추가

## 저장
- 브라우저 세션 안에서만 유지 (`st.session_state`) — 새로고침하면 초기화됨
- 파일 저장/누적은 지금 범위 밖 (기능 1의 발주 리스트와 동일한 방식)

## 화면 구성
`streamlit_app.py`에 탭 추가: `발주 리스트 | 리드타임 분석 | 개발단계·승인원 일정`

이 탭 안에 두 영역:
1. **입력 폼** — 위 데이터 모델 항목을 입력받아 세션에 추가
2. **보드 뷰** — 개발단계별로 열(컬럼)을 나누어(DV1차/DV2차/…/DVR/PV1차/…/PVR) 그 단계에
   있는 모델명 카드를 나열 (모델별 최신 레코드 기준)
3. **캘린더 뷰** — 승인원 일정 날짜 기준으로 이번 달 달력 형태(요일별 그리드)에 그 날짜에
   일정이 있는 모델명을 표시. 월 이동(이전달/다음달) 가능
