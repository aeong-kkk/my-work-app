# 개발샘플현황표 자동화 App — 발표자료 (문제 → 해결 → 시연)

> 발표 흐름 요약
> - 문제: 발주할 때마다 엑셀 파일을 손으로 뒤져서 정보를 옮겨 적는 게 번거로웠다.
> - 해결: 엑셀 파일을 끌어다 놓기만 하면 자동으로 정리해주는 웹 화면(App)을 만들었다.
> - 시연: 발주 엑셀 파일을 넣으면 → 정리된 발주 리스트와 리드타임이 자동으로 나온다.

---

## 슬라이드 1 — 표지

**주제**: 개발샘플현황표 자동화 app 소개

**시각적 요소**: App 첫 화면을 띄워둔다 (제목 "현황표 자동화"가 크게 보이는 화면)

**발표 대본**: 안녕하세요. 오늘은 제가 만든 개발샘플현황표 자동화 App을 소개해 드리려고 합니다. 발주할 때마다 반복되던 번거로운 작업을, 이 프로그램이 어떻게 대신해 주는지 직접 보여드릴게요.

---

## 슬라이드 2 — 문제

**주제**: 우리가 겪던 불편함

**시각적 요소**: 발주 엑셀 파일을 열어서, 안에 있는 모델명·수량·날짜 같은 정보를 사람이 하나하나 찾아 옮겨 적는 모습 (실제 발주 엑셀 화면 캡처, 또는 "엑셀 → 사람 손 → 표"로 이어지는 간단한 그림)

**발표 대본**: 저희는 샘플을 발주할 때마다, 엑셀 파일 안에 있는 모델명이나 수량, 날짜 같은 정보를 사람이 직접 찾아서 표로 옮겨 적고 있었어요. 발주가 있을 때마다 매번 반복되는 일이다 보니 시간도 오래 걸리고, 손으로 옮기다 보니 실수도 생기기 쉬웠습니다.

---

## 슬라이드 3 — 해결

**주제**: 그래서 만든 것 — 개발샘플현황표 자동화 App

**시각적 요소**: App의 "발주 리스트" 화면 전체 (안내 문구, 파일 넣는 칸, "추가하기" 버튼이 보이는 상태)

**발표 대본**: 그래서 이 반복 작업을 대신해 줄 화면을 하나 만들었습니다. 발주할 때 쓰는 엑셀 파일을 화면에 끌어다 놓기만 하면, 필요한 정보를 자동으로 읽어서 정리된 리스트로 만들어줘요. 사람이 직접 찾아서 옮겨 적을 필요가 없어지는 거죠.

---

## 슬라이드 4 — 시연 (무엇을 넣는지)

**주제**: 이렇게 넣으면 돼요

**시각적 요소**: 실제 화면에서 발주 엑셀 파일을 드래그해서 넣는 모습을 라이브로 보여준다 (또는 화면 녹화 영상)

**발표 대본**: 직접 보여드릴게요. 발주할 때 쓰는 엑셀 파일을 이렇게 화면에 끌어다 놓고, "추가하기" 버튼만 누르면 됩니다. 정말 이게 전부예요, 따로 뭘 입력하거나 설정할 필요가 없습니다.

---

## 슬라이드 5 — 시연 (무엇이 나오는지)

**주제**: 이런 결과가 나와요

**시각적 요소**: 결과 화면 (모델명·수량·요청일·리드타임이 정리된 표, 다운로드 버튼)

**발표 대본**: 그러면 이렇게 모델명, 수량, 요청일 같은 정보가 자동으로 정리된 표가 나옵니다. 발주일부터 요청일까지 걸리는 기간, 그러니까 리드타임까지 알아서 계산해 주고요. 필요하면 이 결과를 엑셀 파일로 바로 내려받을 수도 있어요.

---

## 슬라이드 6 — 마무리

**주제**: 정리하며

**시각적 요소**: 슬라이드 2(문제)와 슬라이드 5(결과 화면)를 나란히 보여준다 ("전"과 "후" 비교)

**발표 대본**: 정리하면, 예전에는 발주할 때마다 사람이 엑셀을 뒤져서 손으로 정리했다면, 이제는 파일 하나만 끌어다 놓으면 정리된 리스트가 바로 나옵니다. 들어주셔서 감사합니다.
