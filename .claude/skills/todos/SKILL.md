# Todos — 오늘 할 일만 추출

## 무엇을
요약 텍스트에서 완료된 일이나 다른 날짜의 일정은 빼고 "오늘 해야 할 일"만 GPT로 뽑아 보여준다.

## 입력
요약 텍스트 파일 1개. 사용자가 지정하지 않으면 연습용 샘플(`practice/sample-summary-input.md`)을 사용한다. `OPENAI_API_KEY`가 `.env`에 설정돼 있어야 한다.

## 순서
1. `python feature4_extract_todos.py [파일경로]`를 실행한다 (경로 생략 시 기본 샘플 사용).
2. 오늘 할 일이 없으면 그 사실을 그대로 전달한다.
3. 있으면 출력된 "오늘 할 일" 목록을 사용자에게 그대로 보여준다.

## 출력
오늘 해야 할 일만 담긴 번호 목록.
