# Categorize — 메모 AI 카테고리 분류

## 무엇을
`memos/` 폴더의 메모(.md) 파일들을 읽어 각 메모에 어울리는 카테고리를 GPT로 분류해 보여준다.

## 입력
`practice/memos/` 폴더의 `.md` 파일 전체 (별도 입력 불필요). `OPENAI_API_KEY`가 `.env`에 설정돼 있어야 한다.

## 순서
1. `python feature3_categorize_memos.py`를 실행한다.
2. memos 폴더에 파일이 없으면 나온 안내 메시지를 그대로 전달한다.
3. 정상 처리됐으면 출력된 표를 사용자에게 그대로 보여준다.

## 출력
파일명 / 제목 / 카테고리(회의·아이디어·할일·리서치·피드백·기타) 컬럼을 가진 결과 표.
