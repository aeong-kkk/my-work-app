# Weekly Summary

## 목적
사용자가 그때그때 제공하는 주간 데이터 파일들을 읽어 정리 초안 파일 하나를 만든다.

## 입력
- 이번 회차 주간 데이터 파일
- 지난 회차 주간 데이터 파일 (비교 대상)

사용자가 실행 시점에 제공하는 파일 경로를 사용한다. 파일이 지정되지 않으면 사용자에게 어떤 파일을 볼지 확인한다.

## 절차
1. 제공된 데이터 파일들을 모두 읽는다.
2. 핵심 내용을 세 줄로 요약한다.
3. 지난 회차 대비 달라진 점을 한 줄로 덧붙인다. 비교할 지난 회차 데이터가 없으면 "지난 회차 데이터 없음 - 비교 불가"로 명시한다.
4. 챙겨야 할 이슈를 목록으로 정리한다.
5. 위 내용(요약 3줄 + 달라진 점 1줄 + 이슈 목록)을 하나의 정리 파일로 저장한다.

## 출력
요약 + 달라진 점 + 이슈 목록이 담긴 정리 파일 1개.

## 주의사항
- 제공된 자료에 없는 내용은 지어내지 않는다. 근거 없는 추측이나 수치를 포함하지 않는다.
